## 🚀 Overview

AI-FORGE is an **AI-powered multimodal forensic investigation platform** designed to detect digital fraud across **images, documents, videos, and signatures** using classical computer vision, deep learning, and Large Language Models.

Unlike traditional forensic tools that focus on only one type of media, AI-FORGE provides a **single unified investigation workspace** capable of analyzing multiple evidence formats and producing an explainable AI-generated forensic report.

The system is designed for:

- Digital Forensics
- Insurance Fraud Detection
- Banking Fraud Investigation
- Law Enforcement
- Cyber Crime Investigation
- Legal Evidence Verification
- Enterprise Security Teams

---

# 🎯 Problem Statement

Digital fraud has increased dramatically with AI-generated content.

Current forensic tools:

❌ Analyze only one media type

❌ Require manual investigation

❌ Produce difficult-to-read reports

❌ Lack explainable AI reasoning

❌ Cannot combine evidence from multiple sources

AI-FORGE solves this by creating a unified AI-powered forensic investigation platform.

# 🚀 Installation

```bash
git clone https://github.com/YOUR_USERNAME/AI-FORGE.git

cd AI-FORGE
```

Backend

```bash
cd backend

python -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

uvicorn backend.main:app --reload
```

Frontend

```bash
cd frontend

npm install

npm run dev
```
